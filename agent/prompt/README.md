# Runtime context inventory

`packages/session/src/turn-system-prompt.ts` assembles the runtime prompt. `scripts/sync-agent-assets.mjs` generates its core/catalog exports from this directory and the built-in Skills. Package-owned role and transport instructions remain with their runtime handlers.

| Existing section                                              | Current destination                                                                   | Scope and trigger                                                    | Compatibility                                                                               |
| ------------------------------------------------------------- | ------------------------------------------------------------------------------------- | -------------------------------------------------------------------- | ------------------------------------------------------------------------------------------- |
| Terminology, outcome ownership, concise replies, language     | `core/10-core.md`                                                                     | Every new context; compact reminder on resume                        | Original event constants remain for older toolkits                                          |
| Choices and planning boundaries                               | Core plus `planning` Skill                                                            | Offer planning before substantial design; load before planning tools | Legacy planning tool names share the same handlers                                          |
| Tasks                                                         | Core trigger plus `tasks` Skill                                                       | Before tracking agreed work                                          | Durable task records and IDs remain unchanged                                               |
| App help                                                      | `app-help` Skill                                                                      | Before explaining Verity                                             | Existing help catalog and handler remain authoritative                                      |
| Delegation                                                    | `delegation` Skill                                                                    | Before broad reading or delegated work                               | Backend delegation controls remain authoritative                                            |
| Memory                                                        | Core boundaries plus `memory-curate` Skill                                            | Before learning or editing scoped facts                              | Legacy project append executable remains available                                          |
| Visible media                                                 | Core link requirement plus `media-output` Skill                                       | Before generating or comparing media                                 | Existing event attachments remain supported                                                 |
| Publishing and repository conventions                         | `pull-request` Skill                                                                  | Before publishing; current code host is included in core             | GitHub and Forgejo retain their existing handlers; local projects have no publishing action |
| Code review                                                   | `push-review` Skill                                                                   | Before pushing                                                       | Review receipts and hooks remain enforced                                                   |
| Resource safety                                               | Core minimum plus `sandbox-resources` Skill                                           | Before heavy commands or resource changes                            | Legacy resource prompt remains the fallback                                                 |
| Automation                                                    | `automation` Skill                                                                    | Before recurring work                                                | Confirmation card remains the authorization boundary                                        |
| Development servers                                           | Core trigger plus `dev-server` Skill                                                  | Before starting, restarting or previewing a server                   | Legacy executable remains the single implementation                                         |
| Dependencies                                                  | `dependencies` Skill                                                                  | Before installing dependencies                                       | Existing dependency broker and checks remain enforced                                       |
| Knowledge                                                     | Core destinations plus `knowledge-query`, `knowledge-ingest`, `knowledge-lint` Skills | Before retrieval, imports/decisions, or validation                   | Wiki/Raw Sources retain legacy mount paths and immutable records                            |
| Personal Instructions and Memory                              | Server-resolved context snapshot                                                      | Running prompt initiator, or server-owned first-start identity       | Missing identity injects no personal context                                                |
| Project Instructions and Memory                               | Managed `AGENTS.md` and `overview.md` snapshot                                        | Persisted session project                                            | Revision changes rebuild backend context; migration marker prevents resurrection            |
| Knowledge working copy, decision directory and assigned tasks | Conductor runtime announcements                                                       | Refreshed from current project/session state                         | Canonical read-only mounts and working-copy publication remain unchanged                    |
| Assistant, QA, role-specific mandates                         | Package-owned runtime sections                                                        | Stored role/session binding                                          | Never selected by user Instructions or Memory                                               |
| Backend transport, tool aliases, secret names                 | Backend-owned delivery sections                                                       | Current backend and broker capability                                | Configuration isolation and execution authorization remain unchanged                        |

The core and catalog have deterministic byte regression budgets. These do not assert equal token counts across models. Skill format, distribution hashes, loader argument handling and runtime capability inventory are checked independently. A missing or stale Skill manifest keeps the legacy prompt active. Native configuration probes verify managed startup isolation; they do not measure model compliance with Skill triggers.
