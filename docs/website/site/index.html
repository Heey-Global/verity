Why it's safe

Agents inside. Keys outside.

  • Isolated.Every project runs in its own Docker container, sealed off from the host by the gVisor sandbox kernel. Agents never see your machine or other projects.
  • Nothing to steal.No passwords, no tokens in the sandbox. GitHub, Google, and secrets are reached through the broker, only with your approval.
  • Supply chain on a delay.New package releases can wait three days before they install, so a poisoned release has time to be caught before it reaches you.
  • Checked before it leaves.Every push first goes through gitleaks, which scans for leaked secrets, and through a code review gate.

Credential isolation covers Claude Code and Codex today; OpenCode is described separately in the security model. The release delay is optional and reduces risk rather than guaranteeing it.

Get started

Up and running in one command.

On a Linux machine with Docker:

curl -fsSL https://verity.build/install.sh | bash

The installer checks the machine, downloads the signed release, starts it, and shows a pairing code for your first device. To only run the checks, replace bash with bash -s -- --preflight. You need a Claude or ChatGPT subscription or an OpenAI-compatible API key.
