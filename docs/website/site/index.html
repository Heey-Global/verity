Secure by design · Supply-chain protection

Keep Claude and Codex credentials outside agent runtimes.

Run Verity on a workstation, dedicated server, or private cloud. Isolated project containers and external credential boundaries reduce the blast radius of software supply-chain attacks. Claude and Codex provider requests cross a brokered gateway; signing and infrastructure actions are brokered outside the project runtime. OpenCode is supported separately and is not covered by this credential-isolation claim.

On brokered Claude and Codex paths, a compromised dependency may reach the sandbox — but it finds no reusable provider credential.
✓ Claude and Codex tokens stay behind the broker

✓ Git push and infrastructure access are brokered
✓ Secret-manager and database credentials stay server-side
