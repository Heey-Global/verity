Design System

One look for everything Verity.

Colors, type, shapes, components and patterns for the app, the public preview pages and the website. The written specification is design-system.md; this page shows it rendered.

Principles

One visual languageApp, PIN page and website share one palette, one typeface and one set of shapes.
Dark firstEvery decision is made for dark. Light is derived from the same roles and stays readable, without its own polish.
Roles, not valuesComponents use named roles like action or attention, never raw hex values.
Calm by defaultLittle text, quiet actions, color only where it carries meaning. Glow is for brand moments.
One of eachEvery component exists once, with all its states. New screens are assembled from them.
Words, not just colorState is always named in text, so it never depends on color alone.

Rules

Cyan acts, pink signsPink never marks something tappable; cyan never decorates.
Fixed transparencies6 % neutral tints, 14 % tonal fills, 35 % tonal borders — always derived from a role.
Line iconsFeather line icons. In a tappable row cyan on a cyan tile, elsewhere muted. The Premium mark is pink.
